# LoadSpace 컨테이너 로딩 시뮬레이터 PRD

- 문서 버전: 2.0
- 갱신일: 2026-08-03
- 제품 단계: 공개 웹 프로토타입
- 서비스: https://cowpigpapa.github.io/loading-simulator/
- 저장소: https://github.com/cowpigpapa/loading-simulator

## 1. 제품 정의

LoadSpace는 제품의 규격·중량·수량·형상·적층 제약을 입력하면 선택한 컨테이너에 대한 배치, 적재 순서, 컨테이너 수량과 화물 고정재 위치를 계산하고 3D로 보여주는 웹 기반 적재 계획 도구다.

### 문제 정의(SCR)

- **Situation:** 물류 담당자는 서로 다른 제품을 제한된 컨테이너 공간에 안전하게 적재해야 한다.
- **Complication:** 수작업 계획은 회전 조합, 상부 지지, 빈 공간, 작업 순서와 고정재 위치를 동시에 판단하기 어렵고 작업자 경험에 따라 결과가 달라진다.
- **Resolution:** 브라우저에서 제품 데이터와 제약을 검사하고, 휴리스틱 기반 배치 후보를 평가해 컨테이너별 3D 계획과 Excel 작업표를 생성한다.

## 2. 목표

1. 제품 입력부터 3D 적재 계획 생성까지 한 화면에서 완료한다.
2. 안전 적재와 최대 적재의 목적을 명확히 구분한다.
3. 빈 공간이 있어도 위험하게 상부 적재되는 결과를 방지한다.
4. 단일 컨테이너가 부족하면 같은 규격의 복수 컨테이너로 자동 분할한다.
5. 문에서 가장 안쪽 화물부터 작업할 수 있는 적재 순서를 제공한다.
6. 화물 이동 방지를 위한 문쪽 각재·부목과 벽면·화물 간 에어백 위치를 추천한다.

## 3. 비목표 및 안전 고지

- 전역 최적해를 수학적으로 보장하지 않는다.
- 실제 제품의 압축강도, 포장재 마찰계수, 동적 충격과 진동을 계산하지 않는다.
- 차량 축하중, 선박 복원성, 위험물 격리, 냉동 공기 순환을 인증하지 않는다.
- 현재 결과는 작업 검토용이며 실제 상차 전 현장 책임자와 고정재 제조사 지침으로 검증해야 한다.

## 4. 핵심 사용자

| 사용자 | 핵심 업무 | 기대 가치 |
|---|---|---|
| 수출·물류 담당자 | 컨테이너 규격 및 대수 산정 | 견적과 출하 계획 시간 단축 |
| 창고·상차 작업자 | 적재 위치와 순서 확인 | 작업 재판단과 재배치 감소 |
| 물류 관리자 | 계획 검토와 표준화 | 안전 기준 및 결과 형식 통일 |
| 영업·견적 담당자 | 선적 가능 수량 예측 | 초기 물류비 추정 정확도 향상 |

## 5. 사용자 흐름

1. 제품을 직접 등록하거나 Excel/CSV 파일을 업로드한다.
2. 등록 제품의 수량, 눕힘 허용, 상부 적재 금지를 목록에서 수정한다.
3. 20ft, 40ft, 40ft High Cube, 45ft High Cube 중 규격을 선택한다.
4. `안전 적재` 또는 `최대 적재`를 선택한다.
5. 어느 위치의 `시뮬레이션 실행` 버튼이든 눌러 같은 계산을 실행한다.
6. 진행률과 완료 시간을 확인한다.
7. 컨테이너별 3D, 상면, 단계별 적재 순서와 고정재를 확인한다.
8. 컨테이너가 여러 대면 `‹ 현재 / 전체 ›`로 이동한다.
9. 전체 계획을 Excel로 내보낸다.

## 6. 기능 요구사항

### FR-01 제품 입력·관리

- 필드: 제품명, 제품군, 제품 형상, 수량, 개당 중량, 길이, 너비, 높이, 눕힘 허용, 상부 적재 금지.
- 형상은 박스형과 원통형을 지원한다.
- 기본값은 `눕힘 허용 안 함`이다.
- 등록된 제품 수량은 숫자 직접 입력과 위·아래 화살표로 변경한다.
- 등록 후 눕힘 허용과 상부 적재 금지를 수정할 수 있다.
- 데이터가 바뀌면 모든 실행 버튼에 재계산 필요 상태를 표시한다.

### FR-02 Excel/CSV 입력

- `.xlsx`, `.xls`, `.csv`를 지원한다.
- 한글·영문 헤더를 표준 필드로 매핑한다.
- 필수 규격이나 중량이 없거나 0 이하이면 해당 행을 제외하고 오류를 알린다.
- 샘플 CSV 템플릿을 제공한다.

### FR-03 컨테이너

| 규격 | 내부 길이 | 내부 폭 | 내부 높이 | 최대 적재 중량 |
|---|---:|---:|---:|---:|
| 20ft Dry | 5,898mm | 2,352mm | 2,393mm | 28,200kg |
| 40ft Dry | 12,032mm | 2,352mm | 2,393mm | 26,700kg |
| 40ft High Cube | 12,032mm | 2,352mm | 2,698mm | 26,500kg |
| 45ft High Cube | 13,556mm | 2,352mm | 2,698mm | 27,600kg |

- 화물이 한 대에 들어가지 않으면 같은 규격의 다음 컨테이너에 반복 배치한다.
- 최대 50대까지 결과를 생성한다.
- 제품 자체가 선택 컨테이너에 들어가지 않으면 별도 검토 대상으로 표시한다.

### FR-04 공통 배치 제약

- 컨테이너 경계, 제품 간 충돌, 최대 적재 중량을 하드 제약으로 적용한다.
- 바닥면 회전은 항상 허용하며 `눕힘 허용`은 높이 축을 바꾸는 회전을 의미한다.
- 상부 적재 금지 제품 위에는 다른 제품을 놓지 않는다.
- 후보 위치는 배치 후 생성되는 Extreme Point를 사용한다.
- 기본 탐색 순서는 낮은 Z → 안쪽 X → 좌측 Y의 DBLF 원칙을 따른다.
- 동일 조건에서는 가로 공백, 바닥 지지와 사용 깊이를 평가한다.
- 큰 제품과 위험도가 높은 제품은 가능한 한 하부와 안쪽에 우선 배치한다.

### FR-05 안전 적재 모드

- 바닥 배치를 먼저 최대한 채운 뒤 상부 후보를 검토한다.
- 상부 배치의 지지율은 100%를 하드 조건으로 적용한다.
- 화물 중심점이 실제 지지 접촉 영역 안에 있어야 한다.
- 불안정한 세장비의 상부 배치를 제외한다.
- 옆의 빈 바닥 공간보다 상부 적재를 먼저 선택하지 않는다.

### FR-06 최대 적재 모드

- 안전 적재 결과를 시작점으로 추가 적재하는 안과 전체를 새로 고밀도 배치하는 안을 함께 평가한다.
- 상부 적재 금지가 아닌 제품은 적극적으로 2단 이상 후보를 평가한다.
- 최소 지지율 70%, 중심 지지, 하부 취약 화물 금지는 하드 조건으로 유지한다.
- 적재 수량을 1순위로 비교하고 같은 수량이면 사용 깊이가 짧은 결과를 선택한다.
- 공간이 남았는데 한 줄만 길게 배치하는 결과를 줄이도록 내부 공백과 가로 잔여 폭을 평가한다.

### FR-07 원통형 적재

- 원통은 실제 원통 메시로 표시하되 충돌 계산에는 외접 영역을 사용한다.
- 박스 위 원통은 평면 지지율 조건을 만족하면 허용한다.
- 원통 위 박스는 곡면 지지로 판단해 금지한다.
- 원통 위 원통은 중심 오차 15mm 이하, 지름 차이 합계 30mm 이하일 때만 허용한다.

### FR-08 적재 순서

- 실제 작업 순서는 컨테이너 안쪽에서 문쪽 방향으로 생성한다.
- 같은 깊이에서는 아래 화물을 먼저 표시한다.
- 이전, 다음, 자동재생, 슬라이더로 0단계부터 완료 단계까지 볼 수 있다.
- 하부 화물이 배치되기 전에 상부 화물이 공중에 나타나지 않아야 한다.

### FR-09 3D 시각화

- Three.js WebGL로 컨테이너 육면체, 박스, 원통, 부목과 에어백을 표현한다.
- 드래그 회전, 휠 확대·축소, 3D, 상면, 보기 초기화를 제공한다.
- X는 문에서 안쪽, Y는 좌측에서 우측, Z는 바닥에서 위를 뜻한다.
- 부목과 에어백은 각각 ON/OFF 토글을 제공하고 선택 상태를 시각적으로 표시한다.

### FR-10 화물 고정재 추천

- 문쪽에 노출된 화물 폭 전체를 받치는 가로 각재를 표시한다.
- 노출 폭에 따라 부목 3~6개를 좌·중·우에 균등 분산하고 바닥 못 고정 형태로 표현한다.
- 좌측·우측·안쪽 벽과 화물 사이의 연속 빈 공간이 100mm 이상이면 바닥부터 에어백을 추천한다.
- 벽면 간극이 600mm를 넘으면 각 백이 600mm 이하가 되도록 여러 개로 분할한다.
- 화물 사이 에어백은 간극 120~600mm이고 충돌 없는 경우 추천한다.
- 에어백은 공중에 단독 배치하지 않고 바닥부터 해당 높이까지 이어지게 표현한다.
- 문쪽 잔여 공간은 에어백보다 가로 각재와 부목을 우선한다.

### FR-11 결과 및 Excel 내보내기

- 공간 활용률, 중량 활용률, 적재 수량, 총 적재 중량을 표시한다.
- Excel은 `요약`, `적재계획`, `고정재`, `제품목록` 정보를 포함한다.
- 적재계획에는 컨테이너 번호, 적재 순서, 제품 정보, X·Y·Z, 회전 후 규격과 중량을 포함한다.
- 고정재 시트에는 종류, 관련 제품, 추천 위치와 치수를 포함한다.

### FR-12 실행 상태 및 방문자

- 계산 중 진행률, 계산 대상 컨테이너 번호와 완료 시간을 표시한다.
- 긴 계산 중 브라우저가 응답 없음처럼 보이지 않도록 주기적으로 UI 스레드에 제어를 반환한다.
- 공개 사이트에 한국 시간 기준 오늘 방문자와 누적 방문자를 표시한다.

## 11. 로드맵

- 대표 시나리오 회귀 테스트 확대

### P1 — 적재 품질

- Beam Search 또는 다중 시작 휴리스틱으로 제품 순서 후보 확대

- 사용자 정의 컨테이너·팔레트·고정재 규격
- PDF 작업 지시서와 3D 이미지 포함 보고서

## 13. 출시 게이트

1. 대표 혼합 화물 시나리오에서 경계 초과와 제품 중첩이 0건이어야 한다.
2. 안전 모드에서 상부 화물 지지율 100%와 중심 지지 조건을 모두 만족해야 한다.
3. 적재 순서상 상부 화물이 하부보다 먼저 표시되지 않아야 한다.
4. Chrome과 Edge의 데스크톱·좁은 화면에서 입력, 실행, 3D와 내보내기가 동작해야 한다.
5. Excel 결과로 모든 컨테이너의 배치와 고정재 위치를 식별할 수 있어야 한다.
6. 200개 화물 계산 중 UI 진행 상태가 계속 갱신되어야 한다.
7. 화면과 내보내기 문서에 현장 안전 검토 필요성을 고지해야 한다.
