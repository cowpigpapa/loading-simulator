# LoadSpace 컨테이너 로딩 시뮬레이터

제품 규격과 중량을 입력하거나 Excel/CSV로 업로드해 컨테이너 적재 배치와 순서를 계산하는 브라우저 앱입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. Excel 업로드 기능은 SheetJS CDN을 사용하므로 인터넷 연결이 필요하며, CSV 업로드와 나머지 기능은 오프라인에서도 작동합니다.

## 입력 파일 열

- 제품명
- 제품군
- 길이(mm)
- 너비(mm)
- 높이(mm)
- 중량(kg)
- 수량
- 눕힘허용 (`yes` / `no`, 선택)
- 상부적재금지 (`yes` / `no`, 선택)

화면의 `CSV 템플릿 다운로드`로 예시 파일을 받을 수 있습니다.

## 적재 계획 좌표 읽는 법

- 위치 X: 컨테이너 문에서 안쪽으로 들어간 거리
- 위치 Y: 컨테이너 내부 좌측 벽에서 우측으로 떨어진 거리
- 위치 Z: 컨테이너 바닥에서 위로 올라간 거리
- 배치 길이·너비·높이: 제품을 회전한 뒤 실제로 놓인 방향의 크기

예를 들어 `위치 X=1200, Y=0, Z=900`은 제품 시작점이 문에서 1.2m 안쪽, 좌측 벽에 붙고, 바닥에서 0.9m 위라는 뜻입니다.

적재 순서는 위치 X가 큰 제품, 즉 컨테이너 가장 안쪽 화물부터 시작합니다. 같은 깊이에서는 아래층 제품을 먼저 적재합니다.

선택한 컨테이너 한 대에 화물이 모두 들어가지 않으면 같은 규격의 컨테이너를 추가해 자동 분할합니다. 결과 화면의 `컨테이너 1`, `컨테이너 2`, `컨테이너 3` 탭에서 각 컨테이너의 3D 배치와 적재 순서를 확인할 수 있습니다. 계획 CSV에도 컨테이너 번호가 함께 저장됩니다.

원통형 제품은 입력 화면 또는 업로드 파일의 `형상` 열에서 `원통형`으로 지정합니다. 길이와 너비는 원통의 외경 영역, 높이는 세워 놓았을 때의 높이로 사용됩니다. 충돌 계산에는 안전 여유를 위해 원통을 감싸는 외접 직육면체를 적용합니다.

## 현재 계산 방식

제품의 6방향 회전을 고려하는 휴리스틱 공간 분할 알고리즘을 사용합니다. 중량 한도와 내부 치수는 검사하지만, 실제 출하 전에는 축하중·무게중심·바닥 하중·고정재·위험물 격리 조건을 별도로 검증해야 합니다.
